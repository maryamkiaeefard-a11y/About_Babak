VMP • راهنمای ورود

نحوه ورود به سرور Nether RP

برای ورود به Nether RP، ابتدا VMP را اجرا کنید و وارد بخش لیست سرورها شوید. سرور Nether RP روی پلتفرم VMP قرار دارد و مربوط به Season 02 پروژه است.

۱. اجرای VMP

برنامه VMP را اجرا کنید و صبر کنید تا لانچر به‌طور کامل آماده شود. در صورت وجود به‌روزرسانی، اجازه دهید فرایند آپدیت کامل شود.

۲. ورود به Server List

از داخل VMP وارد بخش Server List شوید؛ این بخش فهرست سرورهای قابل اتصال را نمایش می‌دهد.

۳. جستجوی Nether RP

در قسمت جستجوی Server List عبارت Nether RP را دقیقاً سرچ کنید تا سرور را پیدا کنید.

۴. اتصال به سرور

بعد از پیدا کردن Nether RP، سرور را انتخاب کنید و روی دکمه Connect بزنید تا فرایند ورود به سرور شروع شود.

۵. ورود به دنیای Nether RP

پس از برقراری اتصال، منتظر بمانید تا مراحل ورود و بارگذاری کامل شود. سپس می‌توانید وارد تجربه Nether RP شوید.

نکته مهم: نامی که باید در Server List جستجو کنید Nether RP است و پس از انتخاب آن، دکمه Connect را بزنید.
